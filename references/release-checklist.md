# 发布检查清单

## 内容逻辑

- [ ] 已明确目标读者、阅读任务和一句话核心命题。
- [ ] 每个章节承担不同职责，不靠换标题重复同一观点。
- [ ] 事实、个人判断和推测边界清楚。
- [ ] 案例、数据、图片或亲历能够支持核心结论。
- [ ] 结尾完成了本篇文章需要的理解、行动或情绪收束。
- [ ] 若用户未授权改稿，只给诊断，没有擅自重写正文。

## 个人风格

- [ ] 已读取用户自己的最终发布稿、参考图或明确反馈。
- [ ] 已形成个人风格卡，或明确说明本次使用的是暂定默认值。
- [ ] 当前视觉选择能够解释层级、节奏、密度和装饰逻辑。
- [ ] 没有默认复制 @小晚不在 或参考作者的 IP、署名和完整版式。
- [ ] 用户已经认可的部分没有因局部修改被推翻。

## 正文

- [ ] 使用的是唯一最终正文。
- [ ] 一段未漏，未为排版擅自删改。
- [ ] 平台标题与封面金句分工清楚。
- [ ] 专有名词、数字、来源和图注已核验。

## 层级与装饰

- [ ] 首屏完成了“为什么值得继续看”的任务，没有堆叠无关模块。
- [ ] 新章节进入感明显，不强制使用 `01/02/03`。
- [ ] 大标题下没有无功能的横线割开本章。
- [ ] 没有无功能的贯穿式时间线或竖线。
- [ ] 外框、横线与色块没有互相争抢。
- [ ] 删除装饰后仍有必要阅读锚点。

## 手机端文字

- [ ] 正文字号、颜色与行距符合用户确认值。
- [ ] 用户没有个人标准时，页面左右内边距以 `16px` 为起点。
- [ ] 同一论点内小段保持紧凑，只有新论点、标题和图片关系拉开距离。
- [ ] 标题与正文层级明显。
- [ ] 首屏主标题优先为两行，没有为了强调短语拆出明显过短的第三行，也没有 2～3 字孤行。
- [ ] 正文没有不必要的硬换行。
- [ ] 重点覆盖完整语义。
- [ ] 行内重点与正文同字号，没有因强调自动放大。
- [ ] 强调频率符合个人风格卡，没有机械地每段加下划线。
- [ ] `375–390px` 手机预览中，没有连续超过约 10 行且完全缺少原文重点、标题或证据图片的纯正文区。

## 图片

- [ ] 每张图都能证明正文判断或完成明确的氛围任务。
- [ ] 图片主体足够大。
- [ ] 人物图能看清正文需要证明的人物、动作或产品。
- [ ] 多图已预合成，等高对齐、间距一致。
- [ ] 图注包含画面内容与来源。
- [ ] 复制版已用 `scripts/inline_images.py` 内嵌为 base64，单文件 ≤ 10MB，图片带 `data-w`。
- [ ] 复制版里没有本地路径（`./`、`/Users/`、`file://`）；脚本残留本地路径时应报错，而不是忽略。
- [ ] 图床/远程图片已在后台逐张确认能显示；破掉的图已用 `--inline-remote` 转成 base64 后重粘。
- [ ] 粘贴后图片 `src` 已变成 `mmbiz.qpic.cn`；仍是 `data:image/...` 的，已改用素材库 URL 后重新粘贴。

## 个人识别

- [ ] 使用用户自己的头像、IP 或标识。
- [ ] 图片不是本地临时路径（复制版可以是 base64，发布版必须是 `mmbiz.qpic.cn` 或可访问 URL）。
- [ ] 粘贴后个人识别资产仍存在。
- [ ] 作者签名为用户确认版本。

## 平台规范（官方插件开发规范）

- [ ] 已运行 `gzh-design/scripts/validate_gzh_html.py`，ERROR 为 0；WARNING 已逐条判断并说明。
- [ ] 没有设置任何 `font-family`（代码块等宽字体除外）。
- [ ] 没有 `!important`、`<style>`、`<script>`、`class`、`id`、`position: absolute/fixed`、`float`、`@media`、CSS 变量。
- [ ] 没有写死 `width: NNNpx` 的文字容器；表格用百分比列宽；`<img>` 带 `data-w`，样式为 `max-width: 100%; height: auto`。
- [ ] `line-height` 不小于字号；`height: 0` 或固定高度容器内没有文字（纯图拼接除外）。
- [ ] 没有用 `opacity: 0` 的图片承载画面；没有 `caret-color: transparent`、`text-align: start/end`。
- [ ] `<pre>` 只包代码且可换行；正文段落用 `<section>`／`<p>`。
- [ ] 同标签、同样式、单子节点的嵌套链不超过 10 层。
- [ ] `<span leaf>` 内没有块级元素；没有自行添加 `nodeleaf`。
- [ ] 文字与卡片背景是纯色，渐变只出现在没有文字的装饰块上。
- [ ] 正文对比度 ≥ 4.5:1，大字号／加粗 ≥ 3:1；深色模式下文字、图片与 SVG 仍可读。
- [ ] 使用的 `data-ignore-width`、`data-no-dark`、`data-ignore-dm` 确有必要，并在交付说明中列出。

## HTML 与真实发布

- [ ] 输出包含干净正文 HTML、预览复制版和发布稳定版。
- [ ] 复制按钮与脚本只存在于预览壳；粘贴进后台的是干净正文。
- [ ] 图片没有失效路径。
- [ ] 结尾可保留外框、收束文案和署名式文字，但没有点赞、在看、收藏等不可点击的图标、标签或仿按钮。
- [ ] 已在 `375–390px` 宽度查看长截图，并切深色模式看过一遍。
- [ ] 已复制到公众号后台。
- [ ] 后台或手机预览无乱码、丢图、错位和异常空白。
- [ ] 交付时附了合规结论（静态校验结果／官方实测／真机检查／豁免项）。
- [ ] 最终人工调整已区分为单篇特例或稳定偏好。

全部完成后才标记为可发布。
