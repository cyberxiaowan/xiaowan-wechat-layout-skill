# 发布检查清单

## 内容

- [ ] 使用的是唯一最终正文。
- [ ] 一段未漏，未为排版擅自删改。
- [ ] 平台标题与封面金句分工清楚。
- [ ] 专有名词、数字、来源和图注已核验。

## 层级与装饰

- [ ] 首屏只保留一套完整信息单元。
- [ ] `01/02/03` 新章节感明显。
- [ ] 大标题下没有割开本章的横线。
- [ ] 案例没有贯穿式时间线竖线。
- [ ] 外框、横线与色块没有互相争抢。
- [ ] 删除装饰后仍有必要阅读锚点。

## 手机端文字

- [ ] 正文字号、颜色与行距符合用户确认值。
- [ ] 标题与正文层级明显。
- [ ] 标题没有 2～3 字孤行。
- [ ] 正文没有不必要的硬换行。
- [ ] 重点覆盖完整语义。
- [ ] 每个案例的行内重点不超过 1～2 处。

## 图片

- [ ] 每张图都能证明正文判断。
- [ ] 图片主体足够大。
- [ ] 人物图能看清产品或版型。
- [ ] 多图已预合成，等高对齐、间距一致。
- [ ] 图注包含画面内容与来源。

## 个人识别

- [ ] 使用用户自己的头像/IP/标识。
- [ ] 图片不是本地临时路径。
- [ ] 粘贴后个人识别资产仍存在。
- [ ] 作者签名为用户确认版本。

## HTML 与真实发布

- [ ] 输出包含干净正文 HTML、预览复制版和发布稳定版。
- [ ] 没有平台不支持的复杂样式与脚本。
- [ ] 图片没有失效路径。
- [ ] CTA 不依赖易丢失的复杂 SVG。
- [ ] 已在 `375–390px` 宽度查看长截图。
- [ ] 已复制到公众号后台。
- [ ] 后台/手机预览无乱码、丢图、错位和异常空白。
- [ ] 最终人工调整已记录。

全部完成后才标记为可发布。
