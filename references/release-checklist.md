# 发布检查清单

按任务范围勾选；本地测试将后台/真机/发布项标为未执行，不因此擅自操作账号。所有数值以layout-standard.md为唯一参数源，编辑判断以reading-contract.md为准。

## 内容逻辑

- [ ] 已明确目标读者、阅读任务和一句话核心命题。
- [ ] 每个章节承担不同职责，不靠换标题重复同一观点。
- [ ] 事实、个人判断和推测边界清楚。
- [ ] 案例、数据、图片或亲历能够支持核心结论。
- [ ] 结尾完成了本篇文章需要的理解、行动或情绪收束。
- [ ] 若用户未授权改稿，只给诊断，没有擅自重写正文。

## 个人风格

- [ ] 已读取用户自己的最终发布稿、参考图或明确反馈。
- [ ] 已形成个人风格卡，或明确说明本次使用的是暂定默认值。
- [ ] 当前视觉选择能够解释层级、节奏、密度和装饰逻辑。
- [ ] 已记录完整同款／无首屏版本；同款可以复用公开版式，不复制作者私人 IP 或署名。
- [ ] 同款有识别图时，标题在左、IP 在右；375px 与 390px 均无溢出，无图时不留空槽。
- [ ] 用户已经认可的部分没有因局部修改被推翻。

## 正文

- [ ] 使用的是唯一最终正文。
- [ ] 一段未漏，未为排版擅自删改。
- [ ] 平台标题与封面金句分工清楚。
- [ ] 专有名词、数字、来源和图注已核验。

## 层级与装饰

- [ ] 首屏完成了“为什么值得继续看”的任务，没有堆叠无关模块。
- [ ] 默认同款章节组件完整：左编号、右标题、下行PART及英文标签；用户另选结构时遵循已确认配置。
- [ ] 大标题下没有无功能的横线割开本章。
- [ ] 没有无功能的贯穿式时间线或竖线。
- [ ] 外框、横线与色块没有互相争抢。
- [ ] 删除装饰后仍有必要阅读锚点。

## 手机端文字

- [ ] 正文字号、颜色与行距符合用户确认值。
- [ ] 两版采用同一边距配置；平台外层与正文内层不重复缩进，数值以layout-standard.md及本篇实测为准。
- [ ] 同一论点内小段保持紧凑，只有新论点、标题和图片关系拉开距离。
- [ ] 标题与正文层级明显。
- [ ] 首屏主标题优先为两行，没有为了强调短语拆出明显过短的第三行，也没有 2～3 字孤行。
- [ ] 正文没有不必要的硬换行。
- [ ] 重点覆盖完整语义。
- [ ] 行内重点与正文同字号，没有因强调自动放大。
- [ ] 强调频率符合个人风格卡，没有机械地每段加下划线。
- 手机端单段约五六行时检查是否需要按语义拆段；不按字符数自动切句，不靠加粗替代分段，已确认发布稿优先。

## 图片

- [ ] 每张图都能证明正文判断或完成明确的氛围任务。
- [ ] 图片主体足够大。
- [ ] 人物图能看清正文需要证明的人物、动作或产品。
- [ ] 同组多图按手机可读性决定是否预合成；需要保留的证据图不为拼图删除。
- [ ] 图注按需提供新增信息；保留原有必要图注，外部找图标出处，同源原图可文末统一署源，不逐图机械重复。

## 个人识别

- [ ] 使用用户自己的头像、IP 或标识。
- [ ] 图片不是本地临时路径。
- [ ] 粘贴后个人识别资产仍存在。
- [ ] 作者签名为用户确认版本。

## HTML 与真实发布

- [ ] 输出包含干净正文 HTML、预览复制版和发布稳定版。
- [ ] 没有平台不支持的复杂样式与脚本。
- [ ] 图片没有失效路径。
- [ ] 结尾可保留外框、收束文案和署名式文字，但没有点赞、在看、收藏等不可点击的图标、标签或仿按钮。
- [ ] 已在 `375–390px` 宽度查看长截图。
- [ ] 已复制到公众号后台。
- [ ] 后台或手机预览无乱码、丢图、错位和异常空白。
- [ ] 最终人工调整已区分为单篇特例或稳定偏好。

全部完成后才标记为可发布。

## 两版一致性与最新反馈

- [ ] 有首屏主标题合计最多两行、黑栏一行，375/390px实测无碰撞。
- [ ] 需要图注时用11px（或本篇已确认值），说明与来源同时存在才分行；无图注不留占位，来源不作为普通正文。
- [ ] 普通段落正常间距，只有大层级和长文语义转折增加留白。
- [ ] 两版从原文第一段起正文片段完全相同；首屏新增摘要不替代原文，也不插入无首屏版。
- [ ] 本地预览、真实粘贴、推送状态分开报告。

## 完整交付新增关卡
- [ ] 实际加载包与同款配置正确，没有落回底层默认主题。
- [ ] 正文检测覆盖当前实际字号；375/390均检查标题、段落、文字墙及全部图片，未覆盖不得报通过。
- [ ] 已认可排版及用户最新人工修改保留；局部修改未导致其他字段回退。
- [ ] 横方独立构图、上下同图上传，两种实际裁切均验证；本地预览与后台验证分开。
- [ ] 摘要、署名、简介、链接、图源、原创、合集按实际任务检查；未自动照搬其他平台促销。
- [ ] 草稿已保存有读回证据；真机与公开发布状态如实记录。
- [ ] 按 visual-delivery.md 区分验证有效规则和未验证候选。

## 最新首屏与章节验收
- [ ] 主标题醒目且大于正文，主标题整体不超过两行；独立灰色副标题单独核对，不以副标题藏长标题。
- [ ] 导语为忠于全文的短摘要，非直接搬第一段；两版从原文第一段完整开始。
- [ ] 编号左、标题右，下方PART与英文标签对齐；数字不拆行。
- [ ] 金色关键词随语义安排、无固定数量，未改变文字与限定条件；不靠加粗掩盖文字墙。
- [ ] 原有必要图注保留，新增找图有出处；重复图注省略，同源可集中署源。

- [ ] 只扫强调文字能看清判断、并列项与动作；未把长引文、背景或括号注释整块加粗，必要限定仍清楚。
- [ ] 断段按语义关系，标签与解释紧随；中英混排无明显拉字，不用空格凑行。
- [ ] 孤字按 reading-contract.md 的认可顺序处理；用到 nowrap 兜底的段落已左对齐并标“粘贴未验证”。
- [ ] 同组单行短段用8px段距；文字墙预警已拆分或以 data-dense-accepted 记录理由。
- [ ] X 来源图片位置已对照原文页面，或逐图标注“图位推断”。
- [ ] 组件结构来自 assets/template-snippets.html，参数未漂移。
- [ ] 已逐屏列出概念/并列标签/短动作；emphasisWarnings 已修复或以 data-emphasis-note 写明纯叙述理由；无叠加样式。

- [ ] 按整屏及半屏偏移查看全篇：重点/标签/解释有主次，未以碎段、高亮或装饰替代语义层级；相邻屏密度变化自然。


## 样式完整性与保存证据（交付前必核）
- [ ] 对照本篇已确认组件逐项看图：无额外底色、适用图片细框、编号与英文小标、作者栏、首屏身份；不能由“无溢出”推导均已实现。
- [ ] 有首屏检查卡片；无首屏单独检查正文第一屏的疑问/判断/解释层次，声明及背景不抢主重点。
- [ ] 同类信息跨屏一致，不因截图边界强制换色；没有为凑三层而每段强调。
- [ ] 后台只运行一条写入链；粘贴前后、保存刷新后都确认本次独有的样式标记与完整文字，旧稿读回不能证明新样式被过滤。
- [ ] 最终截图和读回HTML来自同一保存版本；失败备选截图不作为最终证据。二维码生成不等于手机已查看。

- [ ] 文末作者卡、来源、链接、二维码及图片内文字已检查引流信息；必要署名/来源与营销转化分别处理，按visual-delivery.md记录发布候选的最小改动，不宣称原文未改。

- [ ] 两版共用完整个人介绍区，公众号链接/名片按配置保留且指向正确；未因引流检查机械删除正常介绍和入口。
- [ ] 源稿、粘贴后及保存读回均检查文末：最后有效内容后无多余可见空行；编辑器光标占位不误判为读者可见空白。
