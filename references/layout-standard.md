# 中文长文移动端排版起点

以下数值只用于用户尚未形成个人风格时的第一版，不是 @小晚不在 的视觉模板，也不是不可修改的品牌规范。若用户已有稳定视觉值、最终发布稿或参考图，以用户证据为准。

先用 `aesthetic-diagnosis.md` 建立个人风格卡，再决定是否采用这些值。

## 三个基础维度

- **层级**：标题、章节、子标题、正文、重点和图注能够快速区分；
- **节奏**：文字、图片、重点句和留白交替出现，避免连续拥挤；
- **证据**：装饰和图片必须帮助理解，不为填空而存在。

## 视觉变量

| 用途 | 默认值 |
|---|---|
| 页面背景 | `#fdfdf8` |
| 正文 | `14px / #595757 / line-height 1.9–2` |
| 正文强调 | `#23251d / 700` |
| 章节强调色 | `#b17816` |
| 深色结构 | `#1e1f23` 或 `#23251d` |
| 次要文字 | `#65675e` |
| 弱化文字 | `#9ea096` |
| 浅灰底 | `#eeefe9` |
| 暖色重点底 | `#efe4cc` |
| 边框 | `#bfc1b7` |
| 圆角 | 约 `6px` |
| 页面左右内边距 | `16px` |
| 同一论点内小段间距 | 约 `14–18px` |
| 新论点／大段落／标题与正文 | 约 `28–36px` |
| 图片与前后正文 | 约 `40px` |

建议层级：

- 章节编号：约 `34px`；
- 章节标题：约 `22px`；
- 案例标题：约 `19px`；
- 趋势小标题：约 `18px`；
- 图注：约 `11px`。

## 首屏

下面是一种适合案例复盘的参考顺序，不是所有文章的固定骨架：

1. 刊头与日期；
2. 中文主标题；
3. 用户自有识别资产；
4. 一句副标题；
5. 编者按标签；
6. 2～3 个短段落；
7. 一条完整重点句。

教程可以先给结果，个人复盘可以先给真实情境，访谈可以先给人物矛盾。首屏只需完成“让读者知道为什么值得继续看”，不要求凑齐所有组件。

个人识别资产应清楚但不抢标题。不要复制他人的 IP 形象。

## 大章节

`01 + PART + 章节标题 + 英文副标题` 是可选参考，不是强制组件。用户已有编号、纯文字、色块或其他章节体系时，沿用用户体系。

- 标题本身就是锚点；
- 标题下不加横线；
- 编号与标题之间不加竖线；
- 大章节前留白约 `56–62px`；
- 标题到首个内容块约 `34–38px`。

## 案例

案例复盘可以采用：

- 深色 CASE 药丸；
- 案例名同排；
- 机制副标题单独一行；
- 正文；
- 拼图与图注；
- 判断或问题；
- 收束。

案例间距约 `48–52px`。不使用左侧时间线，不用整块外框包住每个案例。

## 文字与断行

- 正文不要硬编码换行。
- 一个段落尽量只承担一个观点。
- 标题与金句按完整语义分行，行长尽量接近。
- 首屏主标题优先控制在两行；不要为了让强调色短语独占一行，机械拆出只有 4～5 个字、且明显短于前两行的第三行。
- 末行若只剩 2～3 个字，优先调整字号、容器宽度或语义分组；未经授权不改写用户标题。
- 长重点句换行后仍须处于同一个强调容器。
- 不对每段自动加下划线。
- 不在同一句同时使用粗体、底色与下划线。
- 行内重点继承正文字号，只改变字重、文字色或下划线，不因强调自动放大字号。
- 在 `375–390px` 手机预览中，连续纯正文尽量不超过约 10 行。接近上限时优先从原文选择完整判断或关键短语作为同字号锚点；其次使用已有标题或证据图片，不编造观点、标题或装饰图。

## 段落与图片间距

- 同一论点内的连续小段保持约 `14–18px`，让阅读关系连续。
- 进入新论点、大段落或标题—正文关系时，才使用约 `28–36px`。
- 图片块与前后正文保持约 `40px`；图注属于图片块内部，不再叠加正文段距。
- 使用单侧 margin 或确认浏览器 margin collapse，避免段前段后机械相加。

## 装饰预算

建议全文最强视觉锚点不超过 5 处。

- 外框用于建立完整区域，不用于包住每个小模块；
- 横线只用于确实需要结束或分隔的地方；
- 色块只承载完整观点；
- 药丸标签用于 CASE 或动作名；
- 删除装饰后，要确认章节仍可辨认。

## 图片组合

| 内容类型 | 推荐组合 |
|---|---|
| 线下空间/IP 餐饮 | 场景横图＋产品/甜品双图 |
| 明星服饰 Campaign | 横向 Hero＋下方两张等宽全身图 |
| 毛绒/领养机制 | 两张正方形横排：角色阵容＋套装/证书 |
| 包装/无障碍产品 | 产品主图＋握持/按压动作 |

原则：

- 图片进入 HTML 前先合成为静态拼图；
- 同排图片等高、对齐、间距一致；
- 人物图要能证明服装版型；
- 产品图要让产品和关键动作足够大；
- 图片数量由证据需要决定，不机械追求一致；
- 图注采用：`画面内容。图片来源：品牌／媒体`。

## 结尾

案例复盘可参考以下顺序；其他文体根据自己的结尾任务调整：

1. `/// END 最后`；
2. 两段收束；
3. 完整金句；
4. 来源；
5. 居中作者介绍；
6. 带细边框的结尾容器，可保留收束文案与 `THANKS FOR READING` 等署名式文字。

不显示点赞、在看、收藏图标、标签或仿按钮，避免让读者误以为可以点击。结尾外框属于结构，不应因删除仿交互而被一并移除。

## 封面

- 横屏主封面建议 `2100×900`；
- 平台标题负责说清案例与主题；
- 封面金句负责提供意义判断；
- 主标题两行以内优先，并充分使用横向空间；
- 不要为了方形裁切把所有内容挤进中央安全区；
- 若需要方形小图，单独使用作者自己的识别资产。
